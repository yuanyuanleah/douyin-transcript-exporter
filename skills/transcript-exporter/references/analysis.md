# 数据洞察分析（采集后自动输出）

本文件定义采集完成后的 4 个数据洞察模块的**口径与输出规范**。执行 Agent 在 Step 5 按本文件实现分析；口径必须与本文件一致，禁止自行改判据。

## 数据源与统一口径

- **数据源优先级**：目标飞书表格实时数据（`lark-cli base +record-list`）> 本地完整采集 JSON（各批次 `_all.json` / 合并 JSON / 本地保存的采集 JSON）。
- **数据完整性要求**：`{博主}_all_videos_sorted.json`（主页全量排序缓存）**仅含 rank/video_id/url/title/likes，不足以支撑互动率诊断、发布时间规律、主题聚类**；这些模块必须基于含评论/转发/发表日期/逐字稿的完整采集数据。若某模块所需字段缺失，该模块不执行或在结论中明确标注"数据范围：仅基于已采集完整字段的 N 条"。
- **字段映射**：点赞（likes/点赞）、评论（comments/评论）、转发（shares/转发）、发表日期（publish_date/发表日期，格式 `YYYY-MM-DD HH:MM(:SS)`）。
- **数字清洗**：所有互动数字必须为整数；带"万"（如 `1.6万`）先换算为整数再计算。
- **缺失与零值处理**：真实 0 与未知值必须区分。点赞为 0 或缺失时不计算评论比/转发比；评论或转发缺失时不计算对应比值，真实 0 则正常计算。各指标只统计其所需字段完整的样本，标注有效 N 与排除数量，不用 0 填补未知值。
- **样本范围**：分页读取当前博主全部已采集记录，按账号名称筛选、video_id 去重（重复记录取最近采集版本），不混入其他博主。默认仅分析已采集样本，不代表全主页；若按 Top N 采集，注明样本偏向高点赞，不能推广为博主整体规律。不足 10 条时标注"样本较少，结论仅供参考"。
- **计算工具**：用 Python（本地脚本）或 `+data-query` 聚合；禁止手工心算。所有聚合值保留 2 位小数。
- **输出形式**：按下方"输出模板"给出结构化分析结论；数据已写入飞书表格时，结论里引用表格链接。

## 模块 1：爆款主题分析

**目的**：回答"这个博主的哪个系列更容易爆"。

**主题提取**：根据当前博主实际内容建立关键词表，公开分组规则；不强制把 AI/科技/生活类视频套进国学分类。以下为国学博主的示例（按出现优先匹配）：
- 庄子 → 庄子系；老子/道德经 → 道德经系；王阳明/心学/知行合一 → 王阳明系；金刚经/佛/禅 → 金刚经系；鬼谷子/谋略/揣情 → 鬼谷子系；孔子/论语/儒家 → 儒家系
- 未命中任何关键词的视频归入"其他"。
- 关键词表可在分析时按博主实际内容扩展（如"易经""孙子兵法"），但扩展后须在结论中说明。

**统计指标**（每个主题组）：
- 视频数 N
- 平均点赞（组内已知点赞总和 / 点赞有效样本数；全博主均值也使用点赞有效样本）
- 平均总互动数（次）=（点赞+评论+转发）总和 / N，仅统计三项都已知的有效样本，分母为该有效样本数，并标注 N（**这是互动次数均值，不是比率**）
- 爆款率 = 点赞 ≥ 已采集样本平均点赞的视频数 / 点赞有效样本数；这是本项目的相对阈值，不是平台认证的爆款标准。

**结论句式**：
- `"{主题A}"系列共 N 条，平均点赞 X 万，爆款率 Y%；"{主题B}"系列共 N 条，平均点赞 X 万，爆款率 Y%。→ 该博主"{主题A}"系列更容易出爆款（或：两系列表现接近，但"{主题A}"数量更多）。`
- 主题组视频数 < 3 条时标注"样本少，仅参考"。

## 模块 2：互动率诊断

**目的**：找出"点赞一般但讨论/转发远超点赞规模"的潜在爆款。

**指标**（均以点赞为分母，不等于以播放量/曝光量为分母的平台互动率）：
- 评论比 = 评论数 / 点赞数（点赞为 0 或缺失时**不计算**，记为"缺失"，不参与中位数与排名）
- 转发比 = 转发数 / 点赞数（同上）

**"高讨论低点赞"判据**（同时满足，仅统计评论比有效的样本）：
1. 评论比 > 样本中位数（全部有效视频评论比的中位数）
2. 点赞数 < 博主平均点赞数
→ 标记为"高讨论低点赞"潜在爆款。
- 评论比有效样本 < 5 条时标注"样本不足，结论仅参考"。

**输出**：按评论比降序列出 Top5（不足 5 条按实际），每条给出：标题、点赞、评论、评论比、是否命中"高讨论低点赞"标记。结论给一句："评论区热度超过点赞规模的视频是这些，可能是内容引发强共鸣/争议，值得优先拆解其文案结构。"

## 模块 3：发布时间规律

**目的**：总结"博主几点发、周几发、什么时候数据最好"。

**指标**（基于发表日期）：
- 小时分布：各小时发布条数（按 `publish_date` 的 HH）
- 星期分布：周一~周日发布条数
- 时段×数据：按小时分组的平均点赞（取 Top3 小时）；按星期分组的平均点赞（取最高星期）
- 时间口径：保留采集页面显示的时间；记录能够确认的时区，未确认时标注"页面显示时间，时区未确认"，不推测服务器时区。毫秒时间戳必须先按确认的时区转换，不能直接按字符串切分。
- **缺失处理**：发布日期缺失或解析失败的样本不进入分布统计，结论标注"有效样本 N 条"。

**输出**：
- 最常发布时段（条数最多的 1~2 个整点/小时段，如"19-20 点"）
- 数据最好的发布时段（平均点赞最高的整点/小时段）
- 最常发布星期 + 数据最好的星期
- 样本 < 20 条时标注"样本较少"。

## 模块 4：主题聚类

**目的**：把全部视频归成几个主题簇，每簇一句话总结。

**聚类方法**：优先用模块 1 的人物/经典关键词聚类；同一关键词下再按标题/介绍里的**议题词**细分（如庄子系下：生死/自由/处世/努力/痛苦）。AI 基于标题+介绍+主题总结字段人工聚类成 3~8 个簇，每个簇的命名用"主题词 + 一句话"。

**输出**：簇列表（按平均点赞降序）：
- 簇名（如"庄子·生死与自由"）
- 条数、平均点赞、代表视频标题（1 条）
- 一句话总结（30 字内，概括该簇核心观点，如"讲生死无常与精神自由，教人放下执念顺势而为"）

## 输出模板（4 个模块汇总为一份分析摘要）

```markdown
## 数据洞察（{博主}，样本 {N} 条，{日期}）
数据范围：{表格链接 或 本地数据来源}；{字段完整度说明，如"互动/日期字段缺失 N 条，相关模块已排除"}

### 1. 爆款主题
- {主题A}系 {N} 条 · 平均点赞 {X}万 · 爆款率 {Y}%
- {主题B}系 {N} 条 · 平均点赞 {X}万 · 爆款率 {Y}%
→ 结论：{一句}

### 2. 互动率诊断（高讨论低点赞）
| 标题 | 点赞 | 评论 | 评论比 | 标记 |
|------|------|------|--------|------|
| ... | ... | ... | ... | ⭐潜在爆款 |
→ 结论：{一句}

### 3. 发布时间规律
- 最常发布：{时段}；数据最好：{时段}（平均点赞 {X}万）
- 最常发布：星期{X}；数据最好：星期{X}

### 4. 主题聚类
- **{簇名}**：{N} 条 · 平均点赞 {X}万 · 代表《{标题}》—— {一句话}
```

- 分析完成后，若用户要求，可将完整分析写成飞书文档/本地 Markdown 交付；默认在会话中直接输出摘要。
- 分析只用已采集的真实数据；任何"推测趋势"类结论（如"可能更容易爆"）必须与统计数字同现，不得脱离数据。
