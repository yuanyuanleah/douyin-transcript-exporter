# 抖音逐字稿导出 Skill

把想研究的抖音视频整理成可以对照阅读的材料。

这个 Skill 描述了在 **豆包工作**中采集视频标题、介绍、逐字稿和互动数据的流程，支持保存到本地文件或写入飞书多维表格。

> 使用前提：豆包工作及其内置浏览器、逐字稿获取能力。当前发布完成了文件检查与打包，尚未在本仓库发布流程中实测采集效果。

## 适合什么任务

- 对照阅读一个账号的多条视频，研究开头、结构和表达。
- 为选题分析准备带来源链接的逐字稿材料。
- 把视频材料与互动数据集中整理到本地或飞书。

## 下载与加载

[下载完整 Skill ZIP](https://github.com/yuanyuanleah/douyin-transcript-exporter/archive/refs/heads/main.zip)，解压后将完整 Skill 目录交给豆包工作加载。请同时保留 `SKILL.md` 和 `references/` 下两份文件。

## 先试一个小任务

```text
请按 douyin-transcript-exporter Skill 执行：
采集这个抖音博主最新 5 条视频：[博主主页链接]
提取完整逐字稿，以及标题、介绍、点赞、评论、转发、发表日期和视频链接。
不用飞书，保存到本地。
逐字稿获取失败时请留空并标明失败原因，不要猜测补写。
```

需要写入飞书时，提供目标多维表格链接，并确认本人账号具有相应权限。

## 输出内容

| 字段 | 内容 |
| --- | --- |
| 账号名称、视频链接 | 保留来源 |
| 标题、介绍 | 视频页面上的文本 |
| 逐字稿 | 获取成功的完整口播文本 |
| 点赞、评论、转发 | 采集时的页面互动数据 |
| 发表日期 | 视频发布时间 |

目标表格包含相应字段时，流程还支持 AI 生成选题方向和主题总结。它们属于 AI 分析，需与原始采集内容区分。

## 文件说明

- `SKILL.md`：完整执行流程。
- `references/douyin.md`：页面采集、登录处理和逐字稿完整性检查。
- `references/lark-write.md`：飞书字段、写入、去重与结果验证。

本次分享保留上述三个原始文件。README 是使用入口说明。

## 使用边界

先从少量视频开始，核对逐字稿、数据和来源链接。整理出的材料用于研究，公开引用或复用时需保留来源并取得必要授权。

逐字稿获取失败时，流程默认不自动下载视频或调用妙记转写；如需启用，需另行明确同意。

问题与反馈可提交到本仓库 Issues。
