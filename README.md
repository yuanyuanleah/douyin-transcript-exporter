# transcript-exporter

采集抖音博主主页 / 单条视频的**公开信息**（标题、文案、完整逐字稿与互动数据），可选写入飞书多维表格或保存到本地文件；采集完成后自动输出**数据洞察分析**。

> **定位**：本工具仅供**个人学习与研究**使用，仅读取平台**公开信息**，请遵守平台规则与法律法规。请勿用于任何商业或滥用用途。

本版本为个人研究场景优化版，在原始采集能力基础上强化了**合规与节奏控制**与**分析能力**。

## 功能亮点

### 采集能力
- 博主主页 / 单条视频 / 分享短链均可作为输入
- 采集字段：账号名称、标题、介绍、**完整逐字稿**、点赞、评论、转发、发表日期、视频链接
- AI 扩展字段：选题方向（多选标签）、主题总结（一句话概括）
- **首次使用引导**：自动引导配置飞书（lark-cli 登录、表格权限），未提供表格时可按**默认模板**自动搭建

### 合规与节奏控制（个人研究场景重点）
- **随机节奏**：全程 2~5 秒随机延迟，禁止固定 sleep(2)
- **妙记回退默认关闭**：不自动走「下载视频 → 飞书妙记转写」链路（下载行为风险更高）
- **账号纪律**：独立小号 + 固定设备，登录一次长期保持，不反复退出重登
- **主页全量排序落盘复用**：一次扫描保存全量排序（`{博主昵称}_all_videos_sorted.json`），分批采集直接复用，不重复滚动扫描主页
- **断点续采**：维护进度文件 `{博主昵称}_progress.json`，中断后续跑跳过已完成、优先重试失败项

### 数据洞察分析（采集后自动输出）
1. **爆款主题分析**：按内容主题（如国学经典、个人成长等）分组，比较平均点赞与爆款率
2. **互动率诊断**：按评论比标出"高讨论低点赞"潜在爆款
3. **发布时间规律**：总结几点发、周几发、什么时候数据最好
4. **主题聚类**：自动归成 3~8 个主题簇，每簇一句话总结

## 安装

1. 把仓库中的整个 `skills/transcript-exporter/` 文件夹（含 `references/` 子目录）复制到豆包工作的 Skills 目录：
   - 个人技能目录：`.user_skills/`
   - 或系统技能目录：`.skills/`
2. 在豆包工作中直接使用即可，示例：

   > "用抖音采集 Skill，采集博主【示例博主】主页 https://www.douyin.com/user/xxxxx 点赞最高的前 20 条视频，写入我的飞书表格，并做数据洞察分析。"

   （博主主页链接换成你要采集的对象即可）

## 使用前提

- 必须在**豆包工作**环境运行（逐字稿获取依赖其内置能力；主页采集使用内置浏览器）
- **选择写入飞书时**，Skill 会引导你完成飞书准备：确认 lark-cli 登录的是本人账号；没有表格时可选择用内置**默认模板**自动搭建（字段：账号名称/标题/介绍/逐字稿/点赞/评论/转发/发表日期/视频链接/选题方向/主题总结）
- 建议将表格权限设为**私密（仅自己可看）**，避免公开暴露
- 内置浏览器登录抖音时建议使用**独立小号**：仅用于读取公开主页信息，不下载视频，逐字稿获取不依赖该账号
